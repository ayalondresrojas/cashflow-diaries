# Cashflow Diaries

Your budget & financial expenses tracker. Matte black / off-white, made by Aya Rojas.

A single-page app (`index.html`), no build step and no server.

## Privacy
Everything you enter is stored only in your own browser (localStorage) on your device. Nothing is sent to any server, and nobody else who visits the site can see your numbers. Use **Settings → Download backup** regularly, because clearing your browser data erases the app's data.

## Publish on GitHub Pages
1. Create a repository (for example `cashflow-diaries`) and upload `index.html` and this README.
2. Go to **Settings → Pages**, set **Source** to *Deploy from a branch*, choose `main` and `/ (root)`, then save.
3. After a minute the site is live at `https://<your-username>.github.io/cashflow-diaries/`.
